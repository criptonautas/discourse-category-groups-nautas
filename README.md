# Discourse Category Groups (Criptonautas fork)

**ENGLISH** | [ESPAÑOL](README.es.md)

Maintained by Criptonautas. Not affiliated with or endorsed by Discourse (Civilized Discourse Construction Kit, Inc.).

Fork of [discourse-category-groups-component](https://github.com/discourse/discourse-category-groups-component). Install the `nautas` branch. The `main` branch keeps an older fork, now superseded.

Differences from the original:

- A muted subcategory no longer moves its parent out of its group.
- Hashtags in category descriptions get their icon.
- Extra links use the same markup as category boxes.
- Extra links can be translated.
- Subcategories can be listed in a group, and their parent stops repeating them as pills.
